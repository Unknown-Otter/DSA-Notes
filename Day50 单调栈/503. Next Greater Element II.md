# 503. Next Greater Element II

> [LeetCode 链接](https://leetcode.com/problems/next-greater-element-ii/)

给定一个**循环数组** `nums`（即 `nums[nums.length - 1]` 的下一个元素是 `nums[0]`），返回每个元素的**下一个更大元素**。如果不存在，返回 `-1`。

## 核心思路

处理循环数组的经典技巧：**逻辑上把数组复制一份接在后面**，遍历 `2n` 次，但只在前 `n` 个位置存结果。这样每个元素都能"环视"整个数组一圈。

不用真的复制数组（浪费空间），用 **`i % n`** 取真实下标即可。

## 关键决策

1. **遍历 `2 * n` 次**：保证每个元素都能看完整圈
2. **`nums[i % n]`**：取模实现"逻辑上的复制"
3. **栈里存"下标"而不是"值"**：因为要按位置填 `res[stack.pop()] = num`，必须知道是哪个位置
4. **单调递减栈**：栈底到栈顶递减，遇到更大的数就弹出栈顶并记录答案
5. **`if (i < n) stack.push(i)`**：第二轮只"消费"栈里残留的元素，不再 push 新下标（优化，避免无用功）

## 代码

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Arrays.fill(res, -1);

        Deque<Integer> stack = new ArrayDeque<>();  // 单调递减栈，存下标

        // 遍历 2n 次，模拟循环数组
        for (int i = 0; i < 2 * n; i++) {
            int num = nums[i % n];  // 取模获取真实下标

            // 当前数比栈顶下标对应的值大 → 栈顶找到答案
            while (!stack.isEmpty() && num > nums[stack.peek()]) {
                res[stack.pop()] = num;
            }

            // 只在前 n 次 push，后 n 次只消费不生产
            if (i < n) {
                stack.push(i);
            }
        }

        return res;
    }
}
```

## 走一遍例子

```
nums = [1, 2, 1], n = 3

i=0, num=1: 栈空 → push 0,  stack=[0]
i=1, num=2: 2>nums[0]=1 → pop 0, res[0]=2 → push 1, stack=[1], res=[2,-1,-1]
i=2, num=1: 1<nums[1]=2 → push 2, stack=[1,2], res=[2,-1,-1]
--- 第二轮开始（不再 push）---
i=3, num=nums[0]=1: 1<nums[1]=2 → 跳过, stack=[1,2]
i=4, num=nums[1]=2: 2>nums[2]=1 → pop 2, res[2]=2 → 2不>nums[1]=2 停止, stack=[1]
i=5, num=nums[2]=1: 1<nums[1]=2 → 跳过, stack=[1]

结束：res = [2, -1, 2] ✓
```

下标 2（第二个 1）在第二轮 i=4 时"绕回来"看到了 nums[1]=2，这就是循环搜索的体现。

## 为什么是 2n 而不是 n+1

最坏情况要考虑两类：

1. **单调递减数组**（如 `[5,4,3,2,1]`）：栈里残留元素最后都是 `-1`，2n 也好 n+1 也好结果一样
2. **答案在"绕一圈"后才出现**（如 `[1,5,3,2,4]`）：下标 4（值 4）需要绕回去看到 nums[1]=5 才能找到答案。这种情况必须走完第二轮

**`2n` 是上界，保证最坏情况也能覆盖**。

## 复杂度

- **时间**：O(n)，每个下标最多入栈一次、出栈一次
- **空间**：O(n)，栈最多存 n 个下标

## 和 496 题的对比

| 维度 | 496 (Next Greater Element I) | 503 (Next Greater Element II) |
|---|---|---|
| 输入 | 两个数组，nums1 ⊂ nums2 | 一个循环数组 |
| 栈存什么 | **值**（去 HashMap 查） | **下标**（按位置填 res） |
| 辅助结构 | HashMap | 直接填 res 数组 |
| 遍历次数 | n | **2n** |
| 关键技巧 | 预处理 + 查表 | **取模模拟循环** |

## 总结

1. **循环数组问题的通用套路**：`2n` 遍历 + `i % n` 取模
2. **单调栈存下标 vs 存值**：看最终答案是"按位置填数组"还是"建立值的映射"
3. 这个 `2n` 技巧不只用于单调栈，比如**循环数组的最大子数组和**（918 题）也是同样思路
