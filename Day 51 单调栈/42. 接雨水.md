# 42. Trapping Rain Water

> [LeetCode 42. Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/)

给定 `n` 个非负整数表示柱状图的高度，每根柱子宽度为 `1`，计算下雨后能接多少雨水。

**示例**：

```
Input:  height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
```

---

## 核心思路：单调栈，横着一层一层算

不同于"按列累加"（双指针/前缀最大值）的解法，**单调栈解法是横着一层一层算**雨水。

每当遇到一个比栈顶高的柱子，就以**当前柱子**为右墙、**栈顶下方的元素**为左墙、**栈顶元素**为凹槽底，算出一个**矩形条**的水量。

栈中**单调递减**地存储**索引**（从栈底到栈顶，对应高度递减），这样 pop 出 bottom 后，新的栈顶天然就是 bottom 的左边界。

## 关键决策

1. **栈存索引，不存高度**：计算宽度时需要位置信息 `i - left - 1`，所以必须存索引，需要高度时通过 `height[stack.peek()]` 取。

2. **触发计算的时机**：当 `height[i] > height[stack.peek()]` 时，说明出现了"右高 - 中低 - 左高"的凹槽，可以接水。

3. **必须用 while 不是 if**：当前柱子可能同时是**多层水**的右边界，要持续 pop 直到栈顶不再矮于当前柱子。

4. **pop 出 bottom 后必须判空**：如果栈空了，说明 bottom 左边没有更高的柱子挡水，这一层接不到水，**break** 跳出 while。

5. **left 用 peek，不能 pop**：因为这一层的 left，**可能是下一层的 bottom**，还要留在栈里继续用。

6. **相等时不需要单独处理**：相等时即使算水高也是 `min - bottom = 0`，等于没算；直接走 push 分支即可。所以 while 条件用严格小于 `<`。

## 计算公式

pop 出 **bottom** 后，**peek** 新栈顶作为 **left**，当前 `i` 为 **right**：

- **水的高度**：`h = min(height[left], height[i]) - height[bottom]`
- **水的宽度**：`w = i - left - 1`
- **本层水量**：`h * w`

宽度直接跨越 `left+1` 到 `i-1` 之间所有索引——这些位置的柱子在**更早的循环中已经被 pop 处理过了**，所以它们上方的"水面"已经被前面层填平，可以直接当作一整层矩形来算。

## 走一遍例子：`height = [4, 2, 0, 3, 2, 5]`

遍历到 `i=5`（高度 5）时，栈中为 `[0, 1, 2, 3, 4]`，触发 while：

**第 1 层**：
- pop 索引 2（高度 0）作为 **bottom**
- peek 索引 1（高度 2）作为 **left**
- 水高 = `min(2, 5) - 0 = 2`，宽 = `5 - 1 - 1 = 3`
- 本层水量 = `2 * 3 = 6`

**第 2 层**：继续 while，`height[1]=2 < 5`
- pop 索引 1（高度 2）作为 **bottom**
- peek 索引 0（高度 4）作为 **left**
- 水高 = `min(4, 5) - 2 = 2`，宽 = `5 - 0 - 1 = 4`
- 本层水量 = `2 * 4 = 8`

**第 3 层**：继续 while，`height[0]=4 < 5`
- pop 索引 0（高度 4）作为 **bottom**
- **栈空了，break**

总水量 = `6 + 8 = 14`

## Java 代码

```java
class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();
        int res = 0;

        for (int i = 0; i < height.length; i++) {
            while (!stack.isEmpty() && height[stack.peek()] < height[i]) {
                int bottom = stack.pop();
                if (stack.isEmpty()) break;  // 没有左边界，接不到水
                int left = stack.peek();

                int h = Math.min(height[left], height[i]) - height[bottom];
                int w = i - left - 1;
                res += h * w;
            }
            stack.push(i);
        }

        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：`O(n)`，每个元素最多入栈和出栈各一次。
- **空间复杂度**：`O(n)`，栈最坏情况下存储所有元素（递减数组）。

## 易错点

- **栈存索引还是高度**：必须存索引，比较时写 `height[stack.peek()]`，不要直接 `stack.peek()`。
- **peek 前判空**：`Deque.peek()` 在栈空时返回 `null`，`height[null]` 会 NPE。while 条件用 `!stack.isEmpty() && ...` 短路保护。
- **pop 出 bottom 后再判空**：这是第二次判空，物理意义是"bottom 左边没柱子挡水"，必须 break。
- **left 用 peek，不要 pop**：left 可能在下一轮成为 bottom，要留在栈里。
- **用 while 不是 if**：一个高柱子可能同时填平多层水。

## 总结

1. **栈中存索引**，维持单调递减（高度递减）。
2. **遍历数组**，对每个 `i`：
   1. 当 `height[i] > height[栈顶]` 时进入 **while**。
   2. **pop** 栈顶作为 **bottom**，立即判空（空则 break）。
   3. **peek** 新栈顶作为 **left**。
   4. 算本层水量：`h = min(height[left], height[i]) - height[bottom]`，`w = i - left - 1`。
   5. 累加 `res += h * w`，继续 while 检查下一层。
   6. 退出 while 后，**push** 当前 `i`。
3. 返回 `res`。
