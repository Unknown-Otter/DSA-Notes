
# 并查集 Union-Find

> 用于处理**不相交集合的合并与查询**的数据结构,核心操作:`find`(查询所属集合) 和 `union`(合并两个集合)。
> 典型应用:连通性判断、最小生成树 (Kruskal)、检测环、动态连通性问题。

---

## 一、核心思想

并查集用**树**来表示集合:
- 每个集合是一棵树
- 树的**根节点**作为该集合的代表 (representative)
- 判断两个元素是否在同一集合 → 比较它们的根是否相同

为了让操作高效,引入两个关键优化:
1. **路径压缩 (Path Compression)** — 加速 `find`
2. **按大小 / 按秩合并 (Union by Size / Rank)** — 加速 `union`

配合两种优化后,均摊复杂度为 **O(α(n))**,α 是反阿克曼函数,实际可视为近似 **O(1)**。

## 二、模板代码 (Java)

```java
class UnionFind {
    private int[] root;
    private int[] rank;  // 此处实际语义为 size (集合大小)

    public UnionFind(int n) {
        this.root = new int[n];
        this.rank = new int[n];
        for (int i = 0; i < n; ++i) {
            this.root[i] = i;   // 初始时每个节点自成一个集合
            this.rank[i] = 1;   // 每个集合大小为 1
        }
    }

    public int find(int x) {
        if (this.root[x] != x) {
            this.root[x] = find(this.root[x]);  // 路径压缩
        }
        return this.root[x];
    }

    public void union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX != rootY) {
            // 保证 rootY 是较大的集合
            if (this.rank[rootX] > this.rank[rootY]) {
                int tmp = rootX;
                rootX = rootY;
                rootY = tmp;
            }
            this.root[rootX] = rootY;           // 小集合挂到大集合下
            this.rank[rootY] += this.rank[rootX];
        }
    }

    public boolean isConnected(int x, int y) {
        return find(x) == find(y);
    }
}
```

## 三、代码逐部分讲解

### 1. 成员变量

- `root[i]`:节点 `i` 的**父节点** (不是最终根,只有路径压缩后才会直指根)
- `rank[i]`:存储**以 i 为根的集合大小**

**⚠️ 命名陷阱**:这里叫 `rank` 但实际是 `size`。区别:
| 策略 | 含义 | 合并时是否累加 |
|------|------|---------------|
| **Union by Rank** | 树的高度 (上界) | ❌ 只有等高时 +1 |
| **Union by Size** | 集合元素个数 | ✅ 累加 |

> 面试时如果被追问,要能区分这两种。本模板是 **Union by Size**。

### 2. 构造函数

```java
for (int i = 0; i < n; ++i) {
    this.root[i] = i;
    this.rank[i] = 1;
}
```

**初始化**:n 个独立的单元素集合,每个节点的父亲是自己,集合大小为 1。

### 3. find — 查找 + 路径压缩

```java
public int find(int x) {
    if (this.root[x] != x) {
        this.root[x] = find(this.root[x]);
    }
    return this.root[x];
}
```

两种情况:
- `root[x] == x`:x 本身就是根,直接返回
- 否则:递归找根,并**把 `root[x]` 直接指向最终根**

**路径压缩示意**:
```
压缩前:5 → 3 → 2 → 1 (1 是根)
压缩后:5、3、2 全部直接指向 1
```

### 4. union — 合并 + 按大小合并

```java
public void union(int x, int y) {
    int rootX = find(x), rootY = find(y);
    if (rootX != rootY) {
        if (this.rank[rootX] > this.rank[rootY]) {
            int tmp = rootX; rootX = rootY; rootY = tmp;
        }
        this.root[rootX] = rootY;
        this.rank[rootY] += this.rank[rootX];
    }
}
```

步骤:
1. 找两个节点各自的根
2. 根相同 → 已在同一集合,跳过
3. 根不同 → 通过 swap 保证 `rootY` 是较大集合
4. 小集合挂到大集合下
5. 更新大集合的 size

**为什么按大小合并?** 让树尽可能扁平。如果总把大树挂到小树下,树会越长越高,`find` 退化成 O(n)。

## 四、find 的两种写法

### 写法 1:递归 + 完全路径压缩 (本模板)

```java
public int find(int x) {
    if (root[x] != x) {
        root[x] = find(root[x]);
    }
    return root[x];
}
```

- ✅ 完全压缩,路径上所有节点直接指向根
- ❌ 极端数据 + 未压缩时,递归深度可能爆栈

### 写法 2:迭代 + 路径减半 (工程更安全)

```java
public int find(int x) {
    while (root[x] != x) {
        root[x] = root[root[x]];  // 每次跳两层
        x = root[x];
    }
    return x;
}
```

- ✅ 无递归,无栈溢出风险
- ✅ 同样是 O(α(n)) 均摊复杂度
- ✅ 工程实践更常用

## 五、复杂度分析

| 操作 | 朴素版本 | + 路径压缩 | + 路径压缩 & 按大小合并 |
|------|---------|-----------|----------------------|
| `find` | O(n) | O(log n) | **O(α(n)) ≈ O(1)** |
| `union` | O(n) | O(log n) | **O(α(n)) ≈ O(1)** |
| 空间 | O(n) | O(n) | O(n) |

> α(n) 是反阿克曼函数,对于宇宙中所有实际可能的 n,α(n) ≤ 4。

## 六、决策框架:什么时候用并查集?

判断题目是否适合用并查集,问自己三个问题:

1. 是否涉及**集合 / 连通分量**的概念?
2. 是否需要**动态合并**集合 (而不是一次性建图)?
3. 是否只需要查询"**是否连通**",不关心具体路径?

如果三个都是 yes,优先考虑并查集。

**典型信号词**:
- 「是否连通」「能否到达」
- 「冗余连接 / 多余的边」
- 「省份 / 朋友圈数量」
- 「岛屿合并 (动态)」
- 最小生成树 (Kruskal)

## 八、模板应用:LC 1971 / 卡码网 107

> [1971. Find if Path Exists in Graph](https://leetcode.com/problems/find-if-path-exists-in-graph/)
> 给定无向图,判断 `source` 到 `destination` 是否存在路径。

### 解法

```java
class Solution {
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        UnionFind uf = new UnionFind(n);
        for (int[] e : edges) {
            uf.union(e[0], e[1]);
        }
        return uf.isConnected(source, destination);
    }
}
```

### 卡码网 107 完整版 (含输入处理)

> ⚠️ 卡码网节点编号从 **1** 开始,LeetCode 从 **0** 开始。注意数组大小要开 `n + 1`。

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();

        UnionFind uf = new UnionFind(n + 1);  // 1-indexed,多开一位
        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int t = sc.nextInt();
            uf.union(s, t);
        }

        int source = sc.nextInt();
        int destination = sc.nextInt();
        System.out.println(uf.isConnected(source, destination) ? 1 : 0);
    }
}
```

## 九、总结

1. **核心数据结构**:`root[]` 存父节点,`rank[]` (或 `size[]`) 存集合大小
2. **两个核心优化缺一不可**:路径压缩 + 按大小/秩合并,共同保证 O(α(n)) 均摊
3. **命名注意**:很多模板把 `size` 写成 `rank`,但只要 `union` 里在累加,本质就是 by size
4. **工程版本**:递归 `find` 有栈溢出风险,生产代码优先用迭代 + 路径减半
5. **应用场景**:动态连通性问题的首选,涉及"是否连通 / 分组 / 合并"且不关心具体路径
