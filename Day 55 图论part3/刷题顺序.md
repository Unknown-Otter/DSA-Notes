# 图论搜索 DFS/BFS 刷题路线

> 涵盖卡码网 105、110 + LeetCode 岛屿系列共 10 道,按**由易到难 + 模板优先 + 同类成组**排序

---

## 完整刷题顺序(共 10 道)

### 🟢 第一阶段:网格 DFS/BFS 模板(吃透基础)

#### 1. LeetCode 200 - 岛屿数量(DFS 版) ⭐ 起点

> https://leetcode.com/problems/number-of-islands/

- 网格 DFS 模板,写到肌肉记忆
- 重点对比**两种 DFS 写法**:
  - 写法一:进入函数判断 `if (visited[i][j] || grid[i][j] == '0') return;`
  - 写法二:调用前判断 `if (合法 && !visited && grid == '1') dfs(...)`
- **推荐写法二**:与 BFS 对称、少一层递归调用栈

#### 2. LeetCode 200 - 岛屿数量(BFS 版)

- 同题再用 BFS 写一遍,对照差异
- 🚨 **核心坑**:必须**入队时**标记 visited,不是出队时
- 否则同一节点会被多次入队 → 超时(面试高频追问点)

#### 3. LeetCode 695 - 岛屿的最大面积

> https://leetcode.com/problems/max-area-of-island/

- 模板第一次变形:「计数 +1」→「累加面积」
- DFS 版用返回值累加,BFS 版用计数器
- **体感**:模板没变,只是统计量变了

---

### 🔷 第二阶段:邻接表图遍历(从网格扩展到一般图)

#### 4. 卡码网 105 - 有向图的完全可达性 ⭐ 思维拐点

> https://www.programmercarl.com/kamacoder/0105.%E6%9C%89%E5%90%91%E5%9B%BE%E7%9A%84%E5%AE%8C%E5%85%A8%E5%8F%AF%E8%BE%BE%E6%80%A7.html

- 从网格图 → 邻接表图,建图方式变了,但搜索套路一样
- **核心问题:什么时候需要回溯?**
  1. 可达性问题 → **不需要回溯**(visited 标记后不撤销)
  2. 求所有路径/排列组合 → **需要回溯**(已掌握的回溯专题)
- 两种 DFS 写法对比(和 200 的两种写法本质相同)
- **终判**:遍历结束后检查 visited 是否全部覆盖

#### 4.5(推荐补充) LeetCode 547 - 省份数量

> https://leetcode.com/problems/number-of-provinces/

- 105 的孪生题,无向图连通分量计数
- 巩固"邻接矩阵/邻接表 + DFS/BFS + visited"的通用套路

---

### 🟦 第三阶段:BFS 求最短路径(无权图最短路模板)

#### 5. 卡码网 110 / LeetCode 127 - 字符串接龙(Word Ladder) ⭐⭐

> https://www.programmercarl.com/kamacoder/0110.%E5%AD%97%E7%AC%A6%E4%B8%B2%E6%8E%A5%E9%BE%99.html
>
> https://leetcode.com/problems/word-ladder/

- **核心认知:无权图最短路径一定用 BFS,不能用 DFS**
- 难点不在搜索本身,而在**怎么建图/找邻居**:
  1. 思路 A:对每个单词,枚举每位换 26 个字母,查 wordSet(**面试推荐**)
  2. 思路 B:预处理通配符桶 `h*t → [hot, hit]`,wordList 大时更快
- **模板套路**:队列 + visited(这里 visited 就是从 wordSet 里删除) + 层数计数
- 进阶:**双向 BFS**(LeetCode 127 的最优解,面试加分项)
- 与 200 BFS 的对比:网格 BFS 邻居是上下左右四方向,这里邻居是"差一个字母的单词",**搜索框架完全一样**

---

### 🟡 第四阶段:反向思维(网格题最重要的一类)

#### 6. LeetCode 1020 - 飞地的数量

> https://leetcode.com/problems/number-of-enclaves/

- 第一次接触反向思维:**直接找孤岛难 → 先淹掉非孤岛**
- 从四条边界的每个 `1` 出发 DFS 标记 → 剩下未标记的 `1` 就是答案

#### 7. LeetCode 130 - 被围绕的区域

> https://leetcode.com/problems/surrounded-regions/

- 和 1020 几乎一模一样的套路,验证你是否真的掌握反向思维
- 把 `1` 换成 `O`,把"淹掉"换成"标记为 X"
- **小技巧**:边界连通的 `O` 临时标记为 `#`,最后扫一遍 `#→O`、`O→X`

#### 8. LeetCode 417 - 太平洋大西洋水流问题 ⭐⭐ 反向思维高峰

> https://leetcode.com/problems/pacific-atlantic-water-flow/

- 难点升级:从"一个边界"变成"两个边界求交集"
- 暴力 O(m²n²) → 反向 BFS/DFS O(mn)
- **关键转换**:「水从高往低流到海洋」反过来 = 「从海洋逆流往高处爬」
- 维护两个 visited 矩阵(pacific、atlantic),最后取交集
- **Google 面试高频**,特别能体现"换视角"的思维能力

---

### 🟠 第五阶段:预处理 + 查询

#### 9. LeetCode 827 - 最大人工岛 ⭐⭐⭐ 网格题最难类

> https://leetcode.com/problems/making-a-large-island/

- 暴力 O(m²n²) → 预处理 O(mn),**两步走**:
  1. 第一遍 DFS:给每个岛打编号(从 2 开始避免和 0、1 冲突),用 HashMap 记 `编号 → 面积`
  2. 第二遍遍历每个 `0`:看上下左右四方向,把**不同编号**的岛面积加起来 + 1
- 🚨 **关键坑**:四个方向可能属于**同一个岛**,必须用 `Set<Integer>` 去重
- **边界情况**:全是陆地时答案是 `m*n`(没有 0 可以变)

---

### 🔵 第六阶段:打破惯性

#### 10. LeetCode 463 - 岛屿的周长

> https://leetcode.com/problems/island-perimeter/

- **反直觉收尾**:不需要 DFS/BFS!
- 两种思路任选其一:
  1. **思路 A(贡献法)**:每个陆地格子贡献 `4 - 相邻陆地数`
  2. **思路 B(边界法)**:每个陆地格子看四方向,遇边界或水就 +1
- 卡哥放最后的用意:**先看清问题本质,别一上来就 DFS**

## 按"思维维度"重新归类

| 维度 | 题目 | 心法 |
|---|---|---|
| **基础模板(网格)** | 200、695 | 双层循环遇到陆地就搜,标记 visited |
| **基础模板(邻接表)** | 105、547 | 邻接表建图 → 同一套搜索框架 |
| **BFS 求最短路** | 110/127 | 无权图最短路一定 BFS,邻居定义灵活 |
| **反向思维** | 1020、130、417 | 直接找难 → 找补集/从边界反推 |
| **预处理 + 查询** | 827 | 一次扫好信息,O(1) 查询,避免重复 DFS |
| **反直觉** | 463 | 看清问题本质,不要惯性 DFS |
| **回溯 vs 不回溯** | 105(不回溯) vs 回溯专题 | 求可达性/计数 → 不撤销;求所有解 → 撤销 |

## 节奏建议

**总时长**:一周到一周半,每天 1-2 题

| 时间 | 题目 | 重点 |
|---|---|---|
| 第 1-2 天 | 200(DFS + BFS)、695 | 模板打牢 |
| 第 3 天 | 105 + 547 | 邻接表图遍历 + 体会"回溯不回溯"的区别 |
| 第 4 天 | 110/127 | BFS 最短路模板(面试高频,可多花时间) |
| 第 5-6 天 | 1020、130、417 | 反向思维一组打通 |
| 第 7-8 天 | 827、463 | 收尾两道特殊思路题 |

## Google L3 重点提示

面试出现频率排序(大致):

1. **127(Word Ladder)** —— Google 老题,可能追问双向 BFS
2. **200 / 695** —— 基础筛人题,写不出直接挂
3. **417** —— 中高频,考察思维拐点
4. **130** —— 中频
5. **827** —— 偶尔出现,但出现就是 follow-up,体现深度

105 和 463 不是 LeetCode 直接热门,但它们教的**底层思维**会在很多变体里复用,值得做。
